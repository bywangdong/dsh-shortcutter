- **切换与新建直输**：`b` / `t` / `e` 展开或收起浏览器、终端、文件；`n c` / `n b` / `n t` 新建会话、浏览器或终端并直接进入输入；`i` 进入当前内容；macOS 下按 `⇧ ⌘ C` 可直接复制当前打开的浏览器网址而不移动焦点。
- **回到快捷模式**：普通区域与地址栏按 `Esc`；终端与网页内按 `⌥ Esc`（可在下方修改）。
- **标签与跳转**：`Tab` / `⇧ Tab` 切换标签；按 `g` 显示标签序号（`1`–`9` 直达）与页面跳转，按 `?` 展开键位提示。
- **搜索会话**　按 `f` 查看最近会话，输入标题或工作区的部分字符进行模糊搜索。新版 DSH 可筛选待处理和未读会话。按 `Tab` 进入筛选，`←` / `→` 切换，`↑` / `↓` 选择结果，`Enter` 打开，`Esc` 返回。
