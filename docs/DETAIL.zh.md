- **切换与新建直输**：`b` / `t` / `e` 展开或收起浏览器、终端、文件；`n c` / `n b` / `n t` 新建会话、浏览器或终端并直接进入输入；`i` 进入当前内容。
- **回到快捷模式**：普通区域与地址栏按 `Esc`；终端与网页内按 `⌥ Esc`（可在下方修改）。
- **标签与跳转**：`Tab` / `⇧ Tab` 切换标签；按 `g` 显示标签序号（`1`–`9` 直达）与页面跳转，按 `?` 展开键位提示。
- **搜索会话**：快捷模式下按 `f`，输入会话名称或工作区关键词；`↑` / `↓` 选择，`Enter` 打开，`Esc` 返回。最近访问优先，不包含已归档会话或子代理会话。
